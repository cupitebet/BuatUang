# Musik Latar (BGM)

Taruh file `.mp3` di folder ini. Saat "Background Music" di-set ke **Random**, aplikasi memilih satu lagu secara acak dari sini. Kalau folder ini kosong, video tetap dibuat tanpa musik latar.

Repo ini sengaja tidak menyertakan lagu. Pakai musik yang memang boleh dipakai ulang, misalnya YouTube Audio Library, Pixabay Music, atau lagu milik sendiri. Musik berhak cipta bisa membuat video kena klaim atau di-mute di TikTok, YouTube, dan Instagram.

Lagu juga bisa diunggah lewat API: `POST /api/v1/musics`.
